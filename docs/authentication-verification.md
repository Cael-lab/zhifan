# 账号与邀请验收

验收日期：2026-11-17。Windows、Node 22.16.0、pnpm 11.0.8，生产模式。

## 功能与隔离

- 真实浏览器完成：站主登录、生成绑定邮箱的邀请码、退出、受邀注册、成员登录。成员没有邀请管理入口，直接调用邀请接口返回 403。
- 无邀请码、错误邮箱、已使用、过期或撤销的邀请不能注册；并发使用同一码仅一个注册成功。客户端提交角色不能提升权限。
- 无登录和伪造 Cookie 的数据请求返回 401；退出后旧会话失效。密码使用带随机盐的 scrypt，数据库不保存原始会话令牌。
- 站主与成员使用不同业务数据库。并发请求、日记、交易详情、附件、设置、JSON 导出和 SQLite 下载均按当前身份隔离。
- 成员猜测站主图片和交易地址时无法读取；跨账号修改失败，删除不会损坏站主原图；逐字节核对原图保持不变。
- 成员 SQLite 备份完整性检查通过，内容不包含站主测试记录。服务器环境中的 AI/行情密钥仅供站主使用。
- 检查跨来源请求拒绝、异常登录请求返回 400、本地 Host 与 Next 内部 URL 不一致时正常登录。

## 界面

- Magic UI Magic Card 鼠标光晕、Border Beam 边框流光，暗色蓝色风格。
- 桌面 1440px、手机 390px 登录/注册检查；中英文切换、减少动画偏好、表单密码确认与隐藏/显示。
- 受检页面无横向溢出，浏览器控制台无错误。截图保存在本地 `output/playwright/`，不提交账号测试数据。
