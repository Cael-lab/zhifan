# Interface languages

The app supports `zh-CN` and `en` using a React context in `components/language.tsx`. The preference is stored under `zhifan-language-v1` in browser localStorage; storage events synchronize other tabs. The provider changes HTML `lang` and the document title without remounting the page or refreshing the router.

The message catalog is `src/lib/messages.json` under `apps/web`. Each row contains `[English, Chinese]`; `translate` accepts either source language. Unrecognized strings pass through, which preserves technical identifiers and external errors. Keep new interface labels in this catalog. `useI18n().t` (locally aliased as `ui`) translates only interface messages and known fixed enums. Never pass user-written notes, account names, titles, free-form tags, or Markdown bodies to it.

Select option labels may be translated, but their explicit `value` must stay unchanged. Language must not affect API keys, query parameters, stored enums, imported data, financial calculations or timezone configuration. Include `ui` in memo dependencies when translated text is built inside a memoized callback. UI components outside the app provider keep their original source labels.

Manual verification on 2026-11-16 used an isolated `JOURNAL_DATA_DIR`:

- English selection persists across reloads; Chinese and English work in both directions.
- Switching while a knowledge editor is open retains the draft title and its input node.
- A translated learning-status option retains its original saved value; saved Chinese/English user content is unchanged after reload.
- Trade table headings update immediately in both directions without losing data or filters.
- Settings, learning detail and mobile navigation were inspected in the browser; the 390px layout has no horizontal overflow.
- Browser tests used temporary records; the normal database was not used for fixtures.

`apps/web/tests/language.test.ts` covers live switching, draft preservation, option values, persistence, cross-tab synchronization, HTML language and safe fallbacks.
