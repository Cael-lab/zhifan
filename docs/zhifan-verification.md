## 浏览器与完整流程

使用独立测试数据库完成：

1. 创建中文知识点，设置状态、标签、适用条件，刷新后内容保留。
2. 添加案例并上传 PNG，刷新后图片保留，图片放大及关闭可用。
3. 创建日记并关联知识点，刷新后内容及关联保留。
4. 创建测试账户并录入一买一卖；成交价 100/104、数量 1、两笔手续费各 1，净盈亏为 2。
5. 保存进出场理由及执行评价，交易标记为已复盘。
6. 交易转案例，复制交易附件和复盘附件，逐字节核对图片内容。
7. 导出个人备份，删除案例再恢复，核对图片和关系；重复导入不重复新增。
8. 旧 revision 写入被拒绝，较新内容未被覆盖。
9. 下载完整数据库，SQLite `integrity_check` 返回 `ok`。
10. 在生产构建上复核案例复制和正文图片链接重写；两类截图均可打开。
11. 检查 390px 手机布局，无横向溢出。
12. 正式服务使用独立的默认数据目录，确认账户和个人记录为空。

浏览器截图留存在本机 `output/playwright/`，未纳入 Git。测试数据库及辅助脚本位于本机 `.qa/`，也未纳入 Git。

## 当前边界

- 当前为本地版本，没有发布公网或推送远程仓库。
- 新增主流程为中文，部分上游高级控件仍为英文。
- 行情、券商同步和 AI 属于上游可选能力；本轮没有使用真实账户或 API 密钥测试外部服务。
- 新增学习与日记 JSON 恢复采用合并方式；完整数据库恢复须先停止应用，详见中文使用说明。
