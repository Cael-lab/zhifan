# 知返：页面设计预览 V1

本目录仅包含用于确认布局的静态 HTML 设计稿和 PNG 预览图，不是已完成的交易应用。不连接账户、不保存输入、不执行交易。所有记录和图表为虚构示例。

设计参考 LuxAlgo Trade Journal 的实际深色主题（背景 #08080a、卡片 #101013、边框 #222228、强调色 #1197e2）与侧栏/卡片布局：
https://github.com/LuxAlgo/trade-journal/blob/main/apps/web/src/app/globals.css

正式产品方向：复用该项目交易能力，增加交易学习、案例库以及日记；不单独设置阅读笔记或随想模块。本次没有修改或部署上游应用。

## 页面

1. 总览
2. 交易学习列表
3. 知识点详情：学习内容、案例库、关联交易
4. 交易记录列表
5. 交易复盘详情
6. 交易录入
7. 日记浏览
8. 日记编辑

打开 gallery.html 查看全部截图；打开 index.html 可以通过侧栏在主要静态页面间跳转。表单和其他控件仅作视觉示意。

截图位于 output/playwright/，宽度 1440 像素；使用浏览器渲染 HTML/CSS/SVG，未使用 AI 生图。

本轮设计范围为桌面核心页面。原项目交易日历、绩效报告及设置页面、手机布局、知识点编辑和案例上传弹窗尚未单独出图。
